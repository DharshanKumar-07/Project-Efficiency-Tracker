# AI-Powered Project Success Predictor
This is a Machine Learning project that predicts the success probability of a software project based on the team's skill composition (Coding, Design, Management, Math).

## 🛠️ Tech Stack
 **Python** (Data generation and logic)
 **Scikit-Learn** (Random Forest Regressor)
 **Streamlit** (Interactive web UI)

## How to run locally
1. Clone this repository.
2. Install the requirements: `pip install -r requirements.txt`
3. Run the dashboard: `streamlit run app.py`
